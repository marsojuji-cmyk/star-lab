# Compounding rounds: 10× → 20× → 30×

Each round **unlocks multipliers**. The product of levers is the system score — not a single model trick.

```bash
lab compound status
lab compound next    # next-steps *rewrite* for current highest round
lab compound round 20x
```

| Round | Meaning | Unlocks when |
|-------|---------|----------------|
| **10×** | Closed loop | joins, shadow volume, golden, chaos budget, body, breaker FSM, factory app, ready_for_canary |
| **20×** | Enforcement | 10× + rollout bridge + armed canary + MAE gate + mode_cap on route |
| **30×** | Evolution | 20× + lever product ≥20 + savings suite ≥50× + compound engine |
